# همراه مطالعه (StudyTrack)

## انتشار با GitHub Pages
1. در GitHub یک Repository عمومی (Public) بساز، مثلاً studytrack.
2. Add file ← Upload files؛ هر ۶ فایل همین بسته را آپلود و Commit کن.
3. Settings ← Pages ← Source: Deploy from a branch ← Branch: main و پوشه‌ی / (root) ← Save.
4. حدود یک دقیقه بعد، اپ در https://USERNAME.github.io/REPO/ باز می‌شود.

## نصب روی گوشی
- اندروید (Chrome): منوی ⋮ ← Install app / Add to Home screen
- آیفون (Safari): Share ← Add to Home Screen

نکته: داده‌ها در مرورگر همان دستگاه ذخیره می‌شوند.
